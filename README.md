# 学术讲座与报告预约管理系统

## 简介

这是一个高校讲座预约管理系统，用 Spring Boot + Thymeleaf + MyBatis 开发的。主要解决学校讲座管理中的几个问题：信息发布不及时、预约流程麻烦、统计数据困难。

系统有三种用户：学生可以浏览和预约讲座，教师可以发布和管理讲座，管理员负责审核和用户管理。

---

## 功能说明

### 学生端

学生登录后可以：
- 浏览所有开放预约的讲座
- 按分类、时间、关键词筛选讲座
- 查看讲座详情，包括时间、地点、主讲人、海报
- 在线预约和取消预约
- 在个人中心查看自己的预约记录
- 收到讲座提醒（开讲前24小时和2小时各一次）
- 修改个人信息和头像（头像上传到src/main/resources/static/avatar，默认头像是Default.jpg）

### 教师端

教师可以：
- 发布新讲座，填写标题、简介、时间、地点等
- 上传讲座海报（海报上传到src/main/resources/static/poster，未上传默认海报是static/images/讲座.jpg）
- 设置预约人数上限
- 选择线上或线下形式
- 发布后需要管理员审核
- 查看自己发布的讲座列表和审核状态
- 查看预约人数统计

### 管理员端

管理员功能：
- 审核教师提交的讲座，可以通过或驳回
- 管理所有用户，包括启用/禁用账号、重置密码
- 维护场地信息，设置容量和状态
- 查看所有预约记录，导出预约名单（Excel）
- 发送通知（单发或群发），管理通知，配置通知模板
- 查看操作日志，导出日志名单（Excel）

## 技术选型

后端用 Spring Boot 3.x，模板引擎是 Thymeleaf，数据库操作用 MyBatis 注解方式。数据库是 MySQL 8.0，导出 Excel 用的 Apache POI。

项目结构：
- controller 层处理 HTTP 请求
- service 层写业务逻辑
- mapper 层操作数据库
- entity 是实体类
- util 放工具类（Excel导出、文件上传）
- config 是配置类（拦截器等）

数据库有这些表：用户表、讲座表、预约表、场地表、通知表、通知模板表、操作日志表。

## 业务流程

### 讲座发布流程

教师发布讲座后，状态是待审核。管理员审核通过后，学生才能看到并预约。如果审核驳回，教师可以修改后重新提交。

### 预约流程

学生点预约后，系统会检查：讲座有没有过期、是否满员、学生是否已经预约过、是不是主讲人本人。都通过了才算预约成功。

### 提醒机制

系统会在这些时候自动发通知：
- 预约成功时立即发送
- 开讲前24小时提醒
- 开讲前2小时再提醒一次
- 讲座取消时通知已预约的学生
- 预约满员时通知发布人

预约表里有字段标记是否已经发过提醒，不会重复发送。

### 权限控制

学生只能浏览和预约，教师能管理自己的讲座，管理员有所有权限。登录时会检查角色，没权限的页面进不去。

## 系统特点

通知模板可以在后台配置，管理员自己改模板，不用动代码。模板里支持变量替换，比如讲座标题、用户名这些。

预约的时候会做多项检查，防止超员、重复预约这些问题。文件上传用 UUID 命名，不会覆盖。头像限制2MB，海报5MB，只允许 JPG/PNG/GIF 格式。

数据库操作都加了事务，保证数据一致性。Cookie 做了签名，防止被篡改。

## 运行方式

需要 JDK、MySQL 、Maven。

先建数据库：
```bash
mysql -u root -p
CREATE DATABASE stu_lecture DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE stu_lecture;
SOURCE src/main/resources/stu_lecture.sql;
```

然后改配置文件 `src/main/resources/application.properties`，把数据库密码改成自己的：
```properties
spring.datasource.url=jdbc:mysql://localhost:3306/stu_lecture?useSSL=false&serverTimezone=Asia/Shanghai
spring.datasource.username=root
spring.datasource.password=你的密码
```

启动项目：
```bash
mvn spring-boot:run
```

浏览器访问 http://localhost:8081

## 项目总结

项目实现了完整的讲座预约流程，从发布、审核到预约、提醒都有。三类用户权限分开，数据统计和导出也做了。

技术上用了 Thymeleaf 做服务端渲染，MyBatis 注解简化数据库操作，拦截器统一处理登录检查。分页查询在数据库层面做的，性能还可以。Excel 导出和文件上传封装成了工具类，代码比较清晰。

后续可以加缓存提升性能，加密码加密，移动端适配也可以优化一下，做数据可视化图表等。
